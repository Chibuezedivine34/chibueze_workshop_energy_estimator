## Project Description

The Workshop Energy Cost Estimator is a Python-based application designed to estimate electricity consumption and operating costs of machines in an engineering workshop.

The program provides a predefined catalogue of workshop machines with suggested power ratings. Users can select machines, adjust their power ratings, enter daily operating hours and calculate their energy consumption and electricity costs.

## Features

1. Preloaded catalogue of 10 workshop machines.
2. Automatic suggested machine power ratings.
3. Option to customise power ratings.
4. Daily and monthly energy calculations.
5. Daily and monthly electricity cost estimation.
6. Machine usage classification.
7. Energy consumption ranking.
8. Identification of the highest energy-consuming machine.
9. Input validation and error handling.

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder.
4. Run the command below:

python workshop_energy_estimator.py

5. Follow the instructions displayed by the program.

## My Own Twist

I introduced an Energy Consumption Ranking System.

This feature compares the daily energy consumption of selected machines and arranges them from the highest energy consumer to the lowest.

I also added machine usage classification to identify light, moderate and heavy operating hours.
